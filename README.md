# Nirvair Sandhu

I build software for learning and support, and I like working on the parts where a good interface has to meet a messy real-world problem.

## Selected work

### [SignalGap](https://github.com/nirvairsndhu/SignalGap)

A synthetic-data prototype for deciding which waiting patient should be reassessed next when observations are stale or missing. It combines risk estimates with a separate estimate of whether fresh observations could change the queue, then records the human decision and updated state.

`Python` · `FastAPI` · `scikit-learn` · `Next.js` · `SQLite` · [Evaluation](https://github.com/nirvairsndhu/SignalGap#evaluation) · *Synthetic data; not for clinical use.*

### [Faultline](https://github.com/nirvairsndhu/faultline-learning)

A physics learning tool that checks an explanation with a targeted simulation, then tests whether the learner can use the corrected idea in a new context. Language extraction interprets the explanation; deterministic code checks the physics and evidence.

`TypeScript` · `Next.js` · `React` · [Repository and screenshots](https://github.com/nirvairsndhu/faultline-learning)
