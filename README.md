# Nirvair Sandhu

I build full-stack decision-support and learning software, including applied ML prototypes where uncertainty matters. Recent projects pair interactive interfaces with systems that make their reasoning inspectable.

## Selected work

### [SignalGap](https://github.com/nirvairsndhu/SignalGap)

Synthetic-data prototype for prioritizing emergency-department reassessments when observations are stale or incomplete.

**Built:** A workflow spanning feature generation, calibrated risk inference with bootstrap spread, simulated information value, queue ranking, API state transitions, and a Next.js operations board with an audit trail.

`Python` · `FastAPI` · `scikit-learn` · `Next.js` · `SQLite` · [Evaluation](https://github.com/nirvairsndhu/SignalGap#evaluation)

*Research prototype; synthetic data only. Not for clinical use.*

### [Faultline](https://github.com/nirvairsndhu/faultline-learning)

Interactive physics learning tool that tests explanations with targeted simulations, then checks revised reasoning in a changed context.

**Built:** A guided answer-to-transfer flow where language extraction interprets explanations and deterministic code validates physics, simulation evidence, and repair.

`TypeScript` · `Next.js` · `React` · [Repository and screenshots](https://github.com/nirvairsndhu/faultline-learning)
