# Nirvair Sandhu

I build full-stack decision-support and learning software, including applied ML prototypes where uncertainty matters.

## Selected work

### [SignalGap](https://github.com/nirvairsndhu/SignalGap)

Synthetic-data prototype for prioritizing ED reassessments when observations are stale or incomplete. A complete workflow joins feature generation, calibrated risk and bootstrap spread, simulated information value, queue ranking, API state changes, and an audited Next.js interface.

`Python` · `FastAPI` · `scikit-learn` · `Next.js` · `SQLite` · [Evaluation](https://github.com/nirvairsndhu/SignalGap#evaluation) · *Synthetic data; not for clinical use.*

### [Faultline](https://github.com/nirvairsndhu/faultline-learning)

Physics learning tool that tests explanations with targeted simulations and checks the repair in a changed context. Language extraction interprets explanations; deterministic code validates physics and evidence.

`TypeScript` · `Next.js` · `React` · [Repository and screenshots](https://github.com/nirvairsndhu/faultline-learning)
