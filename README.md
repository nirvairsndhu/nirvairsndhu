# Nirvair Sandhu

I build software for learning and support.
## Selected work

### [SignalGap](https://github.com/nirvairsndhu/SignalGap)

A prototype for deciding which waiting patient should be reassessed next when observations are stale or missing. It combines risk estimates with a separate estimate of whether fresh observations could change the queue, then records the human decision and updated state.

`Python` · `FastAPI` · `scikit-learn` · `Next.js` · `SQLite` · [Evaluation](https://github.com/nirvairsndhu/SignalGap#evaluation) 

### [Faultline](https://github.com/nirvairsndhu/faultline-learning)

A physics learning tool that checks an explanation with a targeted simulation, then tests whether the learner can use the corrected idea in a new context. 
`TypeScript` · `Next.js` · `React` · [Repository and screenshots](https://github.com/nirvairsndhu/faultline-learning)
